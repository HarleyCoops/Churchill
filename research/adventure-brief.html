Seeing the package as an adventure

The Readme already has a spine. The kit already has the rooms. What we still need is a path a visitor can travel.

This brief starts from a launch of Readme.md as a sequential walk (adventure.html). It does not add historical claims. It asks what a visitor still cannot do or feel, even though the evidence is already in the repository.

The rule does not change: every public sentence still traces to the Ground Truth Ledger.

What the Readme already is

The Readme is not a file listing. It already has an adventure spine:

  • An object — six Cassell volumes and a Chartwell note dated 6 December 1946.
  • A person — Colonel Bryan Charles Fairfax, C.M.G.
  • A route — five Somme phases the ledger can document.
  • A connection — five overlapping threads that explain why Churchill’s reply is not a stranger’s courtesy.
  • A physical test — first-edition marks the visitor can check against photographs.
  • Two open cases — Fairfax’s missing “kind letter,” and the thin Canadian-government provenance.

The problem is presentation. Those beats are published as a long scroll, then split again across a portal of equal cards, a deck, a map, a gallery, and a flythrough. A visitor can graze. They cannot yet travel.

What we need to see

1. One door

The research portal currently offers six destinations of equal weight. An adventure has a start. Needed: a first step that is always the letter, then a forced next beat. adventure.html is that door.

2. Memory between rooms

Map, gallery, timeline, and deck do not know which chapter sent you. Landing on the map from Trones Wood should open on that pin. Every room needs a “return to the walk” that resumes the next chapter.

3. Examine mode for the letter

The note is short enough to be seen whole: Chartwell stationery, handwritten “Dear Captain Fairfax,” typed thanks, typed “Colonel Bryan Fairfax, C.M.G.,” punch hole, the 25s. NET flap in the same photograph. Needed: a single-object lamp, not a gallery grid.

4. Stand on each Somme beat

The Readme already writes July 1916 as five phases. The flythrough already thinks in travel, settle, hold, orbit. The HTML does not yet. Per beat, only where the ledger allows a place: NLS crop, verbatim sentence, map pin, memorial only at Maricourt.

5. The missing letter as a quest

Fairfax’s letter to Churchill is the live unknown. The finder tool already queries archives. Visitors never see a result or a silence from inside the story.

6. Return to the object

After Guillemont, the 1946 note has to be read again. That return is the destination: who Fairfax was, why Churchill answering him is documented, what the volumes are, and what remains lost.

Recommended next build

Beat-aware exits from the walk into the map and the gallery. Somme chapters open the map on the matching marker. The letter chapter opens an examine view. Each of those pages grows a “continue the walk” link back to the next chapter.

Do not rebuild the deck, the flythrough, or the finder until the walk can hand a visitor from chapter to place and back again. No new historical narrative. No reconstructed routes.

If a future page needs a sentence that cannot point at a ledger row, it does not ship. The adventure is a way of walking evidence, not a way of decorating it.
