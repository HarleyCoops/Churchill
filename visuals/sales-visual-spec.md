# Sales Visual Spec (Ground-Truth Only)

Objective: create visuals that increase buyer trust and perceived provenance value for the Churchill/Fairfax set.

## Non-negotiable standard
- No hypotheses.
- No inferred movements unless directly sourced.
- Every on-screen claim must map to a ledger ID in `research/ground-truth-ledger.md`.

## Visual 1 — Provenance Hero (30–45s)
**Purpose:** quickly establish authenticity and significance.

### Required on-screen facts
- Churchill note date: 6 Dec 1946 (GT-001)
- “Dear Captain Fairfax” (GT-002)
- Recipient identification: Colonel Bryan Fairfax, C.M.G. (GT-003)
- Book identification: first edition Cassell, *The Gathering Storm* (GT-004)

### Shot plan
1. Macro shot: note paper texture/signature block.
2. Overlay callout: exact date and salutation quote.
3. Cut to title page / edition identifiers.
4. Close with “Documented evidence only” slate.
